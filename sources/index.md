# Sources & corrections
Post-specific assertions should cite official records, approved publications, or other clearly identified sources where appropriate.
Each citation should identify the source document or web page, relevant section, and publication or effective date if known.
Report factual errors through the Post's [public email](mailto:{{ site.data.post.contact.email }}) or [desk telephone](tel:+1{{ site.data.post.contact.phone | remove: '-' }}). Do not use repository issues to disclose member information, personal contact details, or confidential records.
