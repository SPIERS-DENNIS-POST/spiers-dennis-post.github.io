# Accessibility
We want this website to be readable and easy to use on phones, computers, and assistive technologies. The pages use standard HTML and do not require JavaScript to view their content.
We aim to follow WCAG 2.2 AA accessibility guidance, although the site has not undergone a formal accessibility audit.
